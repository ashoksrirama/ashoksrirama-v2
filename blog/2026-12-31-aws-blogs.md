### Reducing LLM Cold-Start Times on Amazon EKS: A Benchmark of Eight Model Loading Strategies

This post benchmarks eight strategies for loading large language model weights on Amazon EKS, using Meta's Llama 3.1 405B-Instruct-FP8 (454 GB) as the test model. It compares HuggingFace Hub direct download, FSx for Lustre, Amazon EFS, Mountpoint for Amazon S3, S3 with s5cmd init container, S3 with Run:ai Model Streamer, Amazon ECR container image, and Amazon EBS Snapshot approaches — measuring cold-start time, effective throughput, and monthly cost. The s5cmd init container strategy emerged as the fastest and most cost-effective at 5 min 31 sec, while the Run:ai Model Streamer offered the simplest configuration at 8 min 28 sec.

### Securing .NET Microservices with Entra ID on AWS

This post demonstrates how to implement secure service-to-service authentication for .NET microservices running on AWS container services using Microsoft Entra ID (formerly Azure AD) with the OAuth 2.0 client credentials flow. It walks through an e-commerce scenario where an Order Service, Inventory Service, and Pricing Service each authenticate via Entra ID before communicating, ensuring only registered and trusted services can access protected endpoints across the chain.
